# Notion Workspace Guidelines

## Workspace Members vs Guests

### Members

Members are users who have access to the workspace and can collaborate across the workspace.

- On the Notion Free Plan, having more than one workspace member triggers block usage restrictions.
- For team collaboration where users need broad workspace access, members can be used.
- Paid plans support unlimited blocks with workspace members.

### Guests

Guests are external collaborators invited to specific pages only.

- Guests do not have workspace-wide access.
- Guests can view, comment, or edit pages they are explicitly invited to.
- Guests are preferred when users only need access to specific documentation pages rather than the entire workspace.

---

## Block Usage Limits

### What is a Block?

A block is any individual piece of content inside Notion, including:

- Text blocks
- Headings
- Lists
- Tables
- Images
- Videos
- Database entries
- Other embedded content

Each content element added to a Notion page counts as a block.

---

## Free Plan Block Limits

### Single-person workspace

- Unlimited blocks.

### Workspace with multiple members

- Maximum of 1,000 blocks per workspace.
- After reaching the limit, additional content creation is restricted unless the workspace upgrades to a paid plan.

> Note: Deleting blocks does not reduce the block count because Notion counts total blocks created in the workspace.

---

## Recommended Workspace Practice

To avoid unnecessary block limitations:

- Keep the number of workspace members limited.
- Add collaborators as guests when they only need access to specific documentation pages.
- Organize documentation into structured pages rather than duplicating content.
- Avoid creating unnecessary duplicate pages or blocks.
- Use linked pages and databases where appropriate.

---

## Access Recommendation for Lab Documentation

For the Laboratory for Cybernetics documentation:

| User Type | Recommended Access |
|---|---|
| Core contributors | Workspace Members |
| External collaborators/reviewers | Guests |
| Public documentation | Shared pages or published pages |

This maintains workspace organization while avoiding unnecessary block usage restrictions.
